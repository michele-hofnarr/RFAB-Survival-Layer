# RFAB Survival Layer

Лёгкий отдельный слой выживания для модпака **RFAB** (Requiem-based Skyrim SE):
сон, сытость, холод с гипотермией и прогрессирующие болезни. Не интеграция
Bethesda Survival Mode — из неё взята только логика климата и список ледяных
пещер, ни одного файла.

- **Тестировалось на:** `RFAB SE XI - Respect Edition [ver. 09.07.2026]`.
- **Порядок загрузки:** `RFAB_SurvivalLayer.esp` — **ниже `RFAB.esp`**.
- **TimeScale:** 10 (RFAB ставит сам), т.е. 1 игровой час = 6 реальных минут.
  Все тайминги калиброваны под это.
- **Зависимости** (все есть в паке): PapyrusUtil, powerofthree's Papyrus
  Extender, MCM Helper, SkyUI.
- Всё опционально и настраивается в MCM (`RFAB Survival`).
- ESL-флаг можно ставить после того, как убедишься, что всё работает.

---

## 1. Что это

Три «оси потребностей» (**СОН**, **СЫТОСТЬ**, **МОРОЗ**) и две системы болезней
(**свои 5**, плюс **обёртки над болезнями RFAB**), поверх которых надстроена
**гипотермия**.

Общий принцип: оси штрафуют **максимум** пула (Health / Magicka / Stamina) и
скорость передвижения — **не реген**. Штраф — это отрицательный Value Modifier
от **базового** размера пула, поэтому он корректно живёт при сейв/лоаде и не
конфликтует с Requiem. Урона «в потолок» нет: суммарный штраф ограничен
`PenaltyCap` (85 %), суммарное замедление — `SpeedCap` (30 %).

Вампиры (`ActorTypeUndead`) освобождены от сна и сытости (их кормёжку ведёт
Requiem), но холод и гипотермия на них действуют.

Контроллер (`_RSL_Controller`) опрашивает состояние раз в `PollInterval` секунд
(деф. 1). Виджет HUD показывает три полоски (сон / сытость / мороз) с насечкой
на пороге штрафа.

## 2. Системы

**СОН.** Счётчик «часов без сна» растёт в реальном времени, кламп на `SleepMax`
(48 ч). Сон в кровати уменьшает счётчик на `SleepRestorePerHour` (6) за каждый
проспанный час. Пока спишь, ось сна на паузе (голод и холод идут). `SleepMinHours`
(1) — минимум проспанного, чтобы сон засчитался; движок и так не даёт спать
меньше часа, так что на дефолте это ни на что не влияет.

**СЫТОСТЬ.** Счётчик «часов без еды» растёт, кламп на `HungerMax` (48 ч).
Съеденная еда уменьшает счётчик пропорционально своему **весу** (`DATA - Weight`):

- обычный продукт (флаг Food) — `HungerFoodPct` (50) % шкалы **за 1 кг**;
- готовое блюдо (`RFAB_SpecialFood`) — `HungerSpecialFoodPct` (100) % за 1 кг;
- сырое мясо (`RFAB_RawFood`) — тоже 100 % за 1 кг, **но** его можно съесть без
  последствий только с «Крепким желудком» (`REQ_KW_StrongStomach`); иначе —
  0 сытости + бросок на пищевое отравление (см. §5).

Т.е. яблоко (вес 0.1) снимает ~5 % шкалы, похлёбка (0.5) — половину, кус сырой
оленины (2.0) — всю. Множитель делится на всех: `− HungerMax × 0.01 × pct × вес`.
Напитки (`RFAB_Drink_*`, вода, алко) сытость **не** дают. Блюдо с 2+ эффектами
без ключа RFAB тоже считается «особым».

**Усталость в бою.** Пока идёт бой (`GetCombatState() == 1`), счётчики сна и
сытости растут в `CombatFatigueMult` раз быстрее (деф. 5). Двухминутная стычка ≈
5 % рампы сна при ×5.

**МОРОЗ.** Аккумулятор `cold` 0–100. Каждый тик `cold += (Severity − Mitigation)
× dt(ч) × ColdRate`; при отрицательной дельте (отогреваешься) она ещё умножается
на `WarmupMult` (5) — согреваешься быстрее, чем мёрзнешь. Штраф начинается с
`ColdGrace` (25). Полная модель — раздел 4.

**БОЛЕЗНИ.** Пять своих болезней (3 стадии каждая) на общем «движке P» (раздел 5)
+ обёртки над 7 болезнями RFAB, добавляющие им стадии 2 и 3. Плюс контроллерные
множители (переносимость холода, эффективность сна, усвоение еды, скорость
голода) по стадиям.

**ГИПОТЕРМИЯ.** Не болезнь (лечение болезней её не трогает — только тепло).
Мгновенно начинается при `cold ≥ HypothermiaThreshold` (90), 3 стадии,
последняя — паралич + нарастающий дренаж текущего HP до смерти.

**HUD.** Виджет SkyUI-ActiveEffects-стиля: три полоски, автоскрытие в норме
(опция), позиция/масштаб/прозрачность/якоря в MCM.

## 3. Логика потребностей и штрафы

### Заполнение оси

`Ramp(value, grace, max)` → доля 0..1:
- `value ≤ grace` → `0` (штрафа нет);
- иначе линейно до `1` при `value ≥ max`.

Для сна `grace = SleepGrace` (16 ч), `max = SleepMax` (48 ч).
Для сытости `grace = HungerGrace` (12 ч), `max = HungerMax` (48 ч).
Для мороза `grace = ColdGrace` (25), `max = 100`.

### Расчёт штрафа

У каждой оси один **основной** пул и два **перекрёстных** плюс вклад в скорость:

| Ось | основной пул | перекрёстные |
|---|---|---|
| СОН | Magicka | Health, Stamina |
| СЫТОСТЬ | Stamina | Health, Magicka |
| МОРОЗ | Health | Magicka, Stamina |

При заполнении оси `f` (0..1):
- основной пул: `−f × PenaltyPrimary` % (деф. **60**) от базы;
- каждый перекрёстный: `−f × PenaltyCross` % (деф. **10**);
- скорость: `f × PenaltySpeed` (деф. **10**) — складывается со всех трёх осей,
  общий кап `SpeedCap` (30);
- любое отдельное урезание пула не выше `PenaltyCap` (85 %).

Итог квантуется вниз до кратного `TierStep` (5): магнитуда меняется только при
переходе через ступень, иначе бы `SetNthEffectMagnitude` дёргал форму заклинания
каждый тик (мусор в сейве и логе).

Магнитуда = `0.01 × ступень × GetBaseActorValue(пул)` и вешается как
Detrimental Value Modifier (движок вычитает).

### Восстановление

- **Сон:** `−SleepRestorePerHour × проспано(ч) × BrSleepMult` (бурая гниль
  режет эффективность: ×0.9 / 0.8 / 0.7 по стадии).
- **Еда:** `−HungerMax × 0.01 × pct × вес × (1 − GwFoodPenalty)`, где `pct` —
  `HungerFoodPct` / `HungerSpecialFoodPct` (% за 1 кг), `вес` — `GetWeight()`
  предмета (кишечные черви режут: −25 / −50 / −80 % по стадии).
- **Мороз:** отогреваешься, когда `Severity < Mitigation` (см. раздел 4).

## 4. Климат / МОРОЗ

`cold += (Severity − Mitigation) × dt(ч) × ColdRate`, дельта < 0 ещё
`× WarmupMult`. `cold` кламп 0–100. Штраф по `Ramp(cold, ColdGrace, 100)`.

### Severity (суровость среды)

**В обычном помещении** (не «ледяная пещера»): у огня и не в воде → `0`; иначе
`SevInterior` (25) `× ночь × вода`.

**В «ледяной пещере»** (локация из списка `_RSL_ColdInteriors` — тот же набор,
что у CC Survival Mode: Альфтанд, Йнгвильд, ледники DLC и т.д.): база
`SevColdInterior` (45) `× ночь × вода`; костёр помогает только на `× FireMult`
(как на улице), «интерьер» не спасает.

**На улице:** `Severity = base × погода × ночь × вода × огонь`.

- **base = `RegionBase()`** — плоская суровость холда:

  | Холд | база | | Холд | база |
  |---|---|---|---|---|
  | Винтерхолд | 40 | | Хаафингар | 20 |
  | Белый Берег (Pale) | 40 | | Вайтран | 10 |
  | Истмарк | 40 | | Фолкрит | 10 |
  | Предел (Reach) | 20 | | Рифт | 10 |
  | Хьялмарк | 20 | | прочее (`RegionDefault`) | 20 |

  Холд определяется по цепочке родительских локаций (PO3), результат кэшируется
  на текущую локацию.

- **Холодный климат** = здесь может выпадать снег: `coldClimate = (wcls == 3) ||
  SnowClimateHere()`. `SnowClimateHere` = `Weather.FindWeather(3) != None` —
  читает **только** список погод локального региона (поэтому в мягком холде во
  время метели, надутой с соседа, вернёт `false` — для этого и `wcls == 3`
  напрямую). **И снежный пол, и высотная рампа работают только в холодном
  климате.**

- **Снежный пол.** В холодном климате база поднимается минимум до
  `RegionSnowFloor` (40).

- **Высота.** В холодном климате: `z ≤ AltitudeLow` (8000) → база холда; между
  `AltitudeLow` и `AltitudeHigh` (14000) → линейно к `RegionAltitude` (100);
  выше → полный `RegionAltitude`. Вне холодного климата рампа не применяется:
  абсолютная Z-высота сама по себе не отличает холодную вершину от тёплой
  (долина Рифтена лежит на Z ~11000, но там тепло).

- **Погодный множитель** (в GLOB — проценты, /100): ясно `WeatherClear` 100 /
  облачно `WeatherCloudy` 150 / дождь `WeatherRain` 200 / снег `WeatherSnow` 200.
- **Ночь** (22:00–06:00): `NightMult` 170.
- **Вода** (плавание): `SwimMult` 220, и обнуляет тепло одежды.
- **Огонь рядом**: `FireMult` 40 (× 0.4). Источник — объект из списка
  `_RSL_FireSources` (костры, горны, плавильни, очаги, факелы-в-мире) в радиусе
  `FireRadius` (400) **или** факел в руке.

### Прямые попадания стихией

Эффекты урона **холодом** (`MagicDamageFrost`) поднимают `cold` на `FrostHitCold`
(2) за попадание, эффекты урона **огнём** (`MagicDamageFire`) — снижают на
`FireHitWarm` (2). Бамп масштабируется на сопротивление:
`× clamp(1 − FrostResist/100, 0, 2)` (для огня — `FireResist`), т.е. полный
иммунитет → 0, уязвимость → до ×2. 0 в MCM отключает совсем. Засчитывается не
чаще одного попадания в 0.5 с (фрост-плащ или каналящееся заклинание дёргают
событие десятки раз в секунду). Разгон `WarmupMult` к этим бампам **не**
применяется. Греться огнём намеренно можно — но горение это урон HP каждый тик,
реальный размен. Только магия (заклинания, крики, ловушки, атронахи, дыхание);
зачарованное оружие пока не учитывается.

### Mitigation (защита от холода)

```
Mitigation = clothingSlots × WarmthPerSlot × Wetness
           + FrostResist × ResistWeight/100
Mitigation = min(Mitigation, 200) × ColdDiseaseMitMult
```

- `clothingSlots` — сколько из 4 слотов (голова 30, тело 32, кисти 33, ступни 37)
  занято; `WarmthPerSlot` = 7. Украшения не учитываются.
- `Wetness` — 0 при плавании, потом линейно сохнет за `DryMinutes` (5) реальных
  минут до 1. Мокрая одежда не греет (слоты зануляются, не капаются).
- `FrostResist` — актёрское сопротивление холоду (AV `FrostResist`, **не**
  `ResistFrost`), `ResistWeight` = 50 (% от него идёт в защиту). Знак Лорда = 25,
  перк акклиматизации = +25.
- `ColdDiseaseMitMult` — простуда режет всю защиту: ×0.85 / 0.75 / 0.60 по стадии.

Пример цели: 4 слота × 7 + 50 × 0.5 = 53.

### Визуал

Ледяная корка на персонаже (шейдер, как у замороженных врагов) при
`cold > ColdVisualThreshold` (90). Отключается тумблером `ColdVisualShader`.

## 5. Болезни

### Движок

У каждой болезни скрытый аккумулятор **P** (−100..+100) в StorageUtil игрока.

- **Свои болезни, отравление, обёртки RFAB** — `StepP` (стохастика): каждые
  ≤ 0.25 ч P дрейфует на `±(100/часы) × (1 ∓ DiseaseResist/100)` (`bad` — любая
  ось выживания прошла половину рампы штрафа → P падает; всё чисто → P растёт);
  затем непрерывный бросок `RandomFloat(0,100) < |P| × dt`. На проке P → 0, ±1
  стадия. Одна стадия за вызов — частый тик догоняет. Нужны **устойчивые**
  условия: нельзя «накопить» плохое время и обналичить разом.
  - «часы» = `DiseaseProgressHours` (24, ухудшение) / `DiseaseDecayHours`
    (24, самоотход).
- **Гипотермия** — `StepLinear` (детерминизм): P += drift × dt; полный +100 →
  +1 стадия, −100 → −1, без броска и без `DiseaseResist`.

Лечение (эффекты «излечить болезнь» — зелья, алтари, заклинания Восстановления):
каждый засчитанный эффект = −1 стадия; P делится пополам. Считается в
`OnMagicEffectApply`.

### Пути заражения

| Болезнь | как подхватить |
|---|---|
| Простуда | бросок раз в игровой час, пока `cold ≥ ColdColdThreshold` (50) |
| Бурая гниль / Кишечные черви / Зелёные споры | удар в ближнем бою от драугра / тролля / рыбы-убийцы (`OnHit`) |
| Пищевое отравление | съесть сырьё на слабый желудок |
| Обёртки RFAB (7 шт.) | штатное заражение RFAB (атакующие спеллы рас), мы это не трогаем |

Шанс простуды линейно растёт от `ColdColdChanceMin` (10 %) на пороге до
`ColdColdChanceMax` (90 %) при `cold ≥ ColdColdChanceMaxAt` (90), затем
`× (1 − DiseaseResist/100)`.

Шанс на удар = `DiseaseHitChance` (100) `× (1 − DiseaseResist/100)`.
Шанс отравления = `FoodPoisonChance` (50 %) за каждый кусок сырья; иммунные
расы с крепким желудком (`REQ_KW_StrongStomach`: орк, каджит, аргонианин,
босмер) не травятся.

Числа — магнитуда эффекта; `%` где не указано «ед». Все эффекты — скрытые
«библиотечные» MGEF; в списке активных эффектов видна **одна** строка на стадию.

| 2 | реген магии −40 %, реген запаса −25 % | ×0.7 |
| 3 | макс. запаса −15 ед, реген магии −70 %, реген запаса −50 % | ×0.5 |

**Бурая гниль** (удар драугра)

| 3 | реген здоровья −100 %, макс. здоровья −20 ед, перенос. вес −35 ед | ×0.7 |

**Кишечные черви** (удар тролля)

### Обёртки над болезнями RFAB

Стадия 1 = штатная болезнь RFAB (её дебафф + бонус Периайта живут как есть).
Стадии 2/3 = копия эффектов RFAB 1:1 (под её же именами) + Периайт-бонус
`× 1.25 / 1.5` + наши добавки. Контроллер подменяет базовый спелл на нашу копию
и ведёт P; лечение откатывает на одну стадию.

| Ключ | Болезнь | добавки стадии 2 | добавки стадии 3 |
|---|---|---|---|
| AT | Атаксия | скор. атаки −10 % | скор. атаки −20 %, скрытность −20 ед |
| RJ | Каменная подагра | скор. атаки −15 % | скор. атаки −30 %, скорость −10 % |
| WB | Разжижение мозга | скор. произн. −5 %, устойчивость −10 ед | скор. произн. −10 %, скор. атаки −5 %, устойчивость −20 ед |
| RA | Хрипунец | макс. здоровья −15 ед | макс. здоровья −30 ед, здоровье −1 ед/сек |
| BF | Костоломная лихорадка | макс. запаса −15 ед, перенос. вес −30 ед | макс. запаса −30 ед, перенос. вес −50 ед, скорость −10 % |
| BRR | Заумь | стоимость всех школ +20 % | стоимость всех школ +40 %, макс. магии −20 ед |
| DR | Изнеможение | скор. атаки −10 %, скор. произн. −20 % | скор. атаки −15 %, скор. произн. −30 %, реген запаса −50 % |

### Обморожения и ожоги (ключ `EL`) — своя логика P

Тканевые повреждения от стихийной магии и глубокого холода. Disease-тип
(«Излечить болезни» откатывает на стадию), но движок P **не** обычный —
`AdvanceElemLesion`:

| вход | что делает с P |
|---|---|
| `cold ≥ ElemLesionColdThr` (90) | дрейф вниз (ухудшение) `−100 / DiseaseProgressHours` /ч |
| любая другая «плохая» ось (голод / сон / умеренный холод) | дрейф 0 — заморожено, ни туда ни сюда |
| все оси в норме (`!DzAnyAxisBad`) | дрейф вверх (заживление) `+100 / DiseaseDecayHours × (1 + Сопр.болезням/100)` /ч |
| попадание стихийным уроном (холод / огонь / **молния**), не чаще 1 / 0.5 c | `P −= ElemLesionHitP (4) × коэф. сопротивления` (FrostResist / FireResist / ElectricResist) |
| «Чистая льняная ткань» [RFAB] съедена | `P += ElemLesionBandageP (10)` |

Заражение (0 → 1): `P ≤ −ElemLesionContractP` (70, от накопленных попаданий),
**или** бросок раз в игровой час, пока **гипотермия на стадии 2+**, с шансом
`ElemLesionHypoChance` (50 %/игр. час) — как остаточное последствие тяжёлого
переохлаждения. Переход стадий 1↔3 — тот же стохастический бросок
`RandomFloat < |P| × dt`, что у остальных болезней.

| Стадия | эффекты |
|---|---|
| 1 Тканевый стресс | скор. атаки −10 %, скор. произнесения −10 %, скрытность −10 ед |
| 2 Термо-неврологический шок | скор. атаки −15 %, произн. −15 %, скрытность −20 ед, скорость −10 %, реген запаса −30 % |
| 3 Обширный некроз | скор. атаки −25 %, произн. −25 %, скрытность −30 ед, скорость −15 %, реген здоровья −50 %, макс. запаса −25 ед, устойчивость −15 ед |

## 6. Гипотермия

Мгновенное начало: `cold ≥ HypothermiaThreshold` (90) на стадии 0 → сразу
стадия 1.

Дальше `StepLinear`:
- `cold ≥ Threshold` → P += `100 / HypothermiaWorsenHours` (1 ч) → стадия +1;
- `cold ≤ HypothermiaRecoverThr` (25) → P −= `100 / HypothermiaRecoverHours`
  (1 ч) → стадия −1;
- между порогами — стадия держится.

| Стадия | эффекты | прочее |
|---|---|---|
| 1 Лёгкая | скорость −10 % | — |
| 2 Умеренная | скорость −25 %, скор. атаки −10 % | — |
| 3 Тяжёлая | скорость −30 %, скор. атаки −20 % | паралич + блок управления; дренаж текущего HP |

**Дренаж стадии 3** квадратичный по времени в стадии:
`HypothermiaDrainPerSec` (1) `× poll × k²`, где `k = 1 + сек_в_стадии_3 /
HypothermiaDrainRamp` (30). Большой пул HP и реген только оттягивают конец.
Лок стадии 3 = AV `Paralysis` + один `PushActorAway` + `DisablePlayerControls`
(камера свободна — смотришь, как замерзаешь).

**Отдых** (ждать/спать) заблокирован на любой стадии гипотермии — **кроме**
случая, когда ты в помещении и отогреваешься (`Severity < Mitigation`): тёплое
укрытие и есть то место, где её отлёживают. Проверяется каждый тик.

## 7. Совместимость

- В RFAB нет своей системы потребностей / усталости / средового холода —
  конфликтов по механикам нет.
- Вампиры (`ActorTypeUndead`): без сна и сытости (кормёжку ведёт
  `Req_FeedPenaltyScript`), холод и гипотермия действуют. При обращении в
  вампира/лича все наши эффекты и стадии болезней снимаются.
- Штраф скорости держится ниже `SpeedCap`, потому что RFAB
  (`RFAB_RestrictMovementOnZeroMS`) запирает игрока на месте при `SpeedMult ≤ 0`.
- Зависимости: PapyrusUtil, powerofthree's Papyrus Extender, MCM Helper, SkyUI —
  всё в паке.

## 8. Приложение: карта переменных RFAB

На что оси и болезни могут влиять. Источник — `RFAB_Menu.psc` (лист персонажа),
`RFAB_ConsoleCommands.psc`, `RFAB_PapyrusFunctions`.

### Ванильные AV — `player.getav <name>` / `setav` / `modav`

| Лист персонажа | AV | примечание |
|---|---|---|
| Броня | `DamageResist` | рейтинг брони |
| Сопр. магии | `MagicResist` | % |
| Сопр. огню / холоду / молнии | `FireResist` / `FrostResist` / `ElectricResist` | % |
| Сопр. яду / болезням | `PoisonResist` / `DiseaseResist` | % (кап 100 = иммунитет) |
| Скрытность | `Sneak` (+ `SneakMod` %) | |
| Шум | `MovementNoiseMult` × 100 | меньше = тише |
| Скорость движения | `SpeedMult` | RFAB запирает игрока при ≤ 0 |
| Скорость атаки | `WeaponSpeedMult` × 100 | 1.0 = 100 % |
| Здоровье / Магия / Запас — макс | `Health` / `Magicka` / `Stamina` | база; Value Modifier + Recover |
| — регенерация % | `HealRateMult` / `MagickaRateMult` / `StaminaRateMult` | «мана ×2 медленнее» = ×0.5 сюда |
| — регенерация базовая | `HealRate` / `MagickaRate` / `StaminaRate` | плоская капля |
| Сила удара 1-руч / 2-руч / безоруж. | `OneHandedSkillAdvance` / `TwoHandedSkillAdvance` / `PickpocketSkillAdvance` (+100 %) | repurposed |
| Скорость произношения | `AlterationSkillAdvance` (+100 %) | repurposed |
| Стоимость школы Разр./Восст./Изм./Илл./Кол. | `DestructionMod` / `RestorationMod` / `AlterationMod` / `IllusionMod` / `ConjurationMod` | цена = `100 − Mod` |
| Устойчивость (poise) | `HeavyArmorSkillAdvance` | repurposed |
| Сопр. «стрелы и болты» | `SpeechcraftSkillAdvance` | repurposed |
| Грузоподъёмность | `CarryWeight` | |

**Реген в RFAB — ДВА независимых слагаемых, НЕ `база × Mult/100`:**
1. **Процентный** — от `*RateMult` и от размера max. Занулишь `*RateMult` →
   уйдёт только эта часть.
2. **Константный** — `*Rate` капает независимо. `*RateMult = 0` его не трогает.

Поэтому «полностью выключить реген» = два эффекта. Гипотермия стадии 3 это
обходит — дренаж текущего HP, реген не трогаем.

### RFAB custom AV — только чтение из Papyrus

`RFAB_PapyrusFunctions.GetCustomActorValue(akActor, "RFAB_KW_...")` (native).
Из консоли напрямую не читаются; влиять — вешать MGEF с нужным `RFAB_KW_*`.

| Лист | ключ |
|---|---|
| Сопр. Ту'ума | `RFAB_KW_BattleShout_Resist` |
| Эффективность блока | `RFAB_KW_BlockEfficiency` |
| Пробитие брони | `RFAB_KW_Penetration` |
| Тиры сопр. Blunt/Pierce/Slash | keyword `RFAB_KW_Armor_Resistance_<...>_Tier1..10` |
| Заряды баша | `RFAB_KW_CurrentBashCharges` |

### Полезные native из `RFAB_PapyrusFunctions`

- `ScriptDamage(victim, attacker, dmg, type, applyCap)` — `type = "disease"`
  учитывает `DiseaseResist` + сложность.
- `GetActorNumeric{Health,Magicka,Stamina}Regen` — плоская часть регена.
- `GetActiveEffectsFromActor`, `GetActiveEffectsTotalInfo` — интроспекция.

### Формы, на которые опирается мод (сверх статов)

- `MagicDamageFrost` / `MagicDamageFire` / `MagicDamageShock` (KYWD, Skyrim.esm) —
  на них ловятся стихийные попадания (мороз/огонь → шкала cold; все три →
  P «обморожений»). Резолвятся по EditorID генератором.
- `RFAB_Bandage` (ALCH, RFAB.esp, EditorID `RFAB_Bandage`) — «Чистая льняная
  ткань»; её приём даёт `+ElemLesionBandageP` к P «обморожений».
- Полный список внешних зависимостей — `SSEEdit_Scripts/RFAB_Validate_Deps.pas`.

### Проверка из консоли

`player.getav DiseaseResist` · `FrostResist` · `MagickaRateMult` ·
`AlterationSkillAdvance` · `DestructionMod` · `SpeechcraftSkillAdvance` ·
`HeavyArmorSkillAdvance` · `WeaponSpeedMult` · `MovementNoiseMult`.
Также в паке есть команды `GetResists` / `GR` (навести на актора) и мод

## 9. MCM (`RFAB Survival`)

Порядок страниц: **HUD · Сон · Сытость · Мороз · Болезни · Штрафы · Debug**.

- **HUD** — вкл/выкл виджета, автоскрытие в норме, позиция X/Y, масштаб,
  прозрачность, якоря по X/Y.
- **Сон** — `SleepGrace`, `SleepMax`, `SleepRestorePerHour`, `SleepMinHours`,
  `CombatFatigueMult` (множитель усталости в бою, действует и на сытость).
- **Сытость** — `HungerGrace`, `HungerMax`, `HungerFoodPct`,
  `HungerSpecialFoodPct` (% шкалы за 1 кг веса).
- **Мороз** — `ColdRate`, `ColdGrace`, `WarmupMult`, `WarmthPerSlot`,
  `ResistWeight`, `DryMinutes`, `FrostHitCold`, `FireHitWarm`; базы 9 холдов +
  `RegionDefault` + `RegionSnowFloor` + `RegionAltitude`;
  погодные/ночной/водный/огонь множители; `SevInterior`, `SevColdInterior`,
  `AltitudeLow/High`, `FireRadius`; визуал (тумблер + порог).
- **Болезни** — `DiseaseEnabled`, `DiseaseProgressHours`, `DiseaseDecayHours`,
  `DiseaseHitChance`, `FoodPoisonChance`, `RfabDzEnabled`, `HypothermiaEnabled`,
  `HypothermiaThreshold`, `HypothermiaWorsenHours`, `HypothermiaRecoverHours`,
  `HypothermiaDrainPerSec`, `HypothermiaDrainRamp`, `ColdColdThreshold`,
  `ColdColdChanceMin/Max/MaxAt`, `ElemLesionEnabled`, `ElemLesionHypoChance`,
  `ElemLesionHitP`; кнопка «вылечить все болезни мода».
  (`ElemLesionColdThr` / `ElemLesionContractP` / `ElemLesionBandageP` —
  GLOB-only, правятся через консоль / `_RSL_Balance.psc`.)
- **Штрафы** — `PenaltyPrimary`, `PenaltyCross`, `PenaltySpeed`, `SpeedCap`,
  `PenaltyCap`, `TierStep`.
- **Debug** — «Мод включён», `PollInterval`, «Отладочный лог», кнопка «Сбросить
  к значениям по умолчанию».

«Мод включён» → выкл: разовый полный тирдаун (снимаются штрафы, стадии болезней,
шейдер, лок гипотермии), монитор продолжает тикать; → вкл: системы
восстанавливаются с чистого листа. Сохранения не нужно.

Дефолты применяются на новой игре и при миграции сейва (`SETTINGS_VERSION` в
контроллере; отстающий сейв разово получает `_RSL_Balance.ResetDefaults()`).

## 10. Отладка

- MCM → Debug → «Отладочный лог» → пишет `Data/RSL_debug.log` (через MO2 VFS
  попадает в `MO2\overwrite\RSL_debug.log`). Выключен — файл не пишется вообще.
- Кнопка «Сбросить к значениям по умолчанию» — все настройки к исходным
  (счётчики не трогает).
- Все балансовые числа — в одном месте: `scripts/source/_RSL_Balance.psc`
  (генерируется из `SSEEdit_Scripts/RFAB_SurvivalLayer_01_Records.pas`,
  процедура `BuildGlobals`).
- Вся видимая игроку русская строка — `SSEEdit_Scripts/RFAB_SurvivalLayer_strings.txt`.
- После обновления RFAB — прогнать `SSEEdit_Scripts/RFAB_Validate_Deps.pas`
  (Apply Script в xEdit): PASS/FAIL по каждой внешней записи, на которую мод
  ссылается. FAIL на строке FormID = RFAB переиндексировал/убрал эту запись.
