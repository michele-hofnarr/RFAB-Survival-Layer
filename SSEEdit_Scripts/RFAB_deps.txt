# RFAB Survival Layer - the external records the mod depends on.
#
# ONE table, two readers:
#   tools/check_deps.py            reads the plugin files directly, no xEdit
#   SSEEdit_Scripts/RFAB_Validate_Deps.pas   the same table inside xEdit
#
# Run the first after every RFAB update. FAIL on a FormID line means that local
# id no longer holds that kind of record in that file - RFAB reindexed it, and
# the hardcoded id in native/src/Core/Forms.cpp has to follow. A rename alone
# still passes, but the report prints the EditorID it found: eyeball the list.
#
# Format:  file | key | SIG | note
#   key '#<hex6>'  match by local FormID   - what the C++ hardcodes
#   key '<edid>'   match by EditorID       - how the generator and
#                                            HasKeywordString() resolve it
# '#' starts a comment, blank lines are ignored.
